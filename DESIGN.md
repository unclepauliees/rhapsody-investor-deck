# Rhapsody Design System

## Overview

The web identity is incumbent. The landscape PDF is an approved extension,
using IAM Seed Round Deck_FINAL.pdf for editorial composition, not branding.
PDF-specific decisions live in docs/pdf-surface.md.

## Colors

Paper #ece7da; ink #1c1712; secondary ink #4c463b; rules #cdc5b2;
signal #c93a1e. Dark PDF pages use #151310 with #f4f0e6 text,
#ded7c5 secondary text, and #f1856a emphasis for contrast.

## Typography

Bodoni Moda for editorial display; Space Mono for compact folios.
PDF body copy uses Arial for dense, legible supporting information, following
the supplied reference's serif/sans division. Display is 49-91px at the
1440x810 design canvas; body 17-23px; disclosures 13-14px. Tracking is zero.
The PDF embeds the brand fonts emitted by the web build.

## Layout

Landscape pages have a fixed 16:9 canvas and 72px horizontal margins. Headers
carry the thesis without an additional eyebrow. Use unframed editorial columns,
thin-rule tables, deliberate photographic pages, and a quiet, consistent folio.
No rounded cards or nested panels. Full-bleed covers use the actual Rhapsody
emblem and approved first-light imagery. Existing web behaviors are unchanged.

## Do's and Don'ts

Keep targets, modeled revenue, and rate comparisons distinct. Never imply a
separate Rhapsody legal entity or raise. Use of funds totals $1M and maps to
milestones. Reuse approved assets with source context; preserve the artist
credit on the first-generation image. Do not treat generated creative images
as documentary proof of flown hardware.

The PDF is a prebuilt static download, not browser printing of the scrolling
site. The link respects the deployment base path, has an accessible name and
keyboard focus indicator, and remains an icon on narrow viewports.
